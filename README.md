# -Data-Driven-Investment-Behavior-Analysis-using-Power-BI-
Built an interactive Power BI dashboard analyzing investor behavior and financial trends. Explored investment preferences, savings goals, and decision factors using real-world data. Applied data cleaning, EDA, and visualization to generate clear, actionable insights.



Investor Behavior & Financial Insights Dashboard (Power BI)

Instead of just working with raw data, I focused on turning it into meaningful insights that anyone can understand through clear and interactive visualizations.
📌 What I Did in This Project
🔹 Explored and Cleaned the Data
Imported raw dataset into Power BI
Cleaned and transformed the data using Power Query
Prepared the data for analysis
🔹 Understood Investment Behavior
Analyzed how different people invest their money
Looked at preferences like:
Equity
Mutual Funds
Bonds
🔹 Compared Investment Patterns by Gender
Identified how investment choices vary between genders
Found interesting behavioral trends
🔹 Connected Savings Goals with Investments
Studied why people invest (wealth creation, security, etc.)
Mapped savings goals with investment types
🔹 Analyzed Investment Duration & Monitoring Habits
Checked how long people prefer to invest
Studied how often they track their investments
🔹 Found Reasons Behind Investment Decisions
Identified key motivations:
Better returns
Tax benefits
Financial safety
🔹 Analyzed Sources of Financial Information
    Explored where people get investment advice:
    Internet
    Newspapers
    Advisors
📊 Dashboard Highlights
    Clean and interactive design
    Easy-to-understand visuals
    Filters to explore data dynamically
    All insights combined in one dashboard
